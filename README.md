## What it does

`main.ts` (Node, no external dependencies) writes one deterministic satirical
sentence to `/output/entry.txt` — a roast of lawmakers who can write a law
fining a crypto exchange a billion dollars, yet print the draft, sign it in
pen, and ask an aide to scan it back into a PDF.

## Run

```sh
node main.ts
```

Then check `/output/entry.txt` (one sentence, 1–320 characters).
